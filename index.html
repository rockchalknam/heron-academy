How it works

  1. Read the exercise. Watch the GIF to see what "done" looks like.
  2. Do it in Challenge Rush. Play as a guest. Do not make an account.
  3. Take your screenshot(s) and turn it in with the exact title (like "Basic Editor 1").
  4. Mr. Nam marks it Pass or Needs Work. Needs Work? Read the note, fix it, turn it in again.
  5. Don't wait around. Start the next exercise while you wait.

Heads up: your levels save in this browser on this laptop, and only when you open the game with the Open Heron Rush button on this page. If you open Challenge Rush any other way, your levels won't be there. Use the same laptop each day, and save often (gear, then SAVE).

Basic Editor 1: Placing Objects

RequiredTiny (<10 min)100 pts

Welcome to the Academy! Every creator starts here. You'll learn the most basic controls in the editor.

  1. Import and open BE1 Starter.
  2. Click the gear. Rename it BE1 First L. (example: BE1 Nam N.) and check Show Grid. Click OK.
  3. You'll see three red outlines. These are templates. Do NOT move or delete them.
  4. BUILD > Platform > Tile. Pick a block and click the first outline to place it.
  5. BUILD > Obstacle > Spikes. Place a spike on the second outline.
  6. With the spike selected, click [R] and press +90. It should point right.
  7. Place any object on the third outline. Click [E] and drag BOTH the X and Y sliders to about 2.00.
  8. Click [V], select the "!" sign, and click Delete.
  9. Press Enter to playtest. Click the square to stop.
  10. Gear > SAVE.
Turn in: a screenshot of the editor (grid on) showing all three objects. Title it "Basic Editor 1".
Pass if: all 3 objects sit on the outlines, the spike points right, the third object is 2x, the "!" sign is gone, and the red outlines are still there.

Basic Editor 2: Editing Objects

RequiredTiny (<10 min)100 ptsDo Basic Editor 1 first

Placing is step one. Now change how objects look and where they sit. Tip: when you select an object, the editor lists its C1 color, Layer, and Z. Use that to check your work.

  1. Import and open BE2 Starter. Rename it BE2 First L.
  2. [V] select Object 1 (left). Click Color, then click the P3 tile (orange). Close the panel.
  3. Select Object 2 (middle). Click Edit Group. Press the left arrow next to ZORDER until it says 1. Click OK.
  4. Select Object 3 (right). Click Edit Group. Press the right arrow next to EDITOR L until it says 1. Click OK.
  5. Gear > check Show Hitbox > OK.
  6. Press Enter and beat the level with zero deaths.
  7. Gear > SAVE.
Turn in: 3 screenshots, one with each object selected so its info shows. Title it "Basic Editor 2".
Pass if: Object 1 shows C1: P3, Object 2 shows Z: 1, Object 3 is on editor layer 1.

Setting Your Goals

RequiredTiny (<10 min)100 pts

Pro level designers set goals so they know what to practice next. Write three:

  1. Short-term (this week): something you can finish soon. Example: "Finish all the Grade 0 required exercises."
  2. Medium-term (this semester): a skill or project. Example: "Build a full level that 3 classmates can beat."
  3. Long-term (a year or more): something big. Example: "Make a level good enough for Herons arcade night."

Make each one specific. "Get better" is too vague. "Beat my own level with zero deaths" is specific.

Turn in: your three goals as text. Title it "Setting Your Goals".
Pass if: three goals, one per timeframe, each specific enough to check off.

Object Hunt

Optional2x points: 200 ptsTiny (<10 min)

Scavenger hunt! Every BUILD tab pops up smaller sets. Dig through them and find five objects that match the clues.

Make a level for it: tick the box next to any level, click Duplicate Level, open the copy, and rename it Hunt First L.

  1. DANGER: touch it and you restart. (Try Obstacle.)
  2. ORB: click it in mid-air to jump again. (Try Platform > Interactive.)
  3. PORTAL: changes how the player moves. (Try Trigger > GameMode or Gravity.)
  4. DECORATION: does nothing to the player. (Try Decoration > Sprite.)
  5. TRIGGER: find one and say what you think it does. (Try Trigger > Aesthetic.)

Gear > check Show Hitbox so you can see which ones can hurt you.

Turn in: a screenshot plus a list of the clue number and object name for all five. Title it "Object Hunt".
Pass if: five objects, each fits its clue, all five named, Hitbox on.
